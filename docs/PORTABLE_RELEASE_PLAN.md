# 通用发布目标与当前差距

目标更新：2026-10-29。用户希望其他玩家安装指定版本的虚拟机后，通过启动脚本准备兼容环境并启动 HELLDIVERS 2；每位玩家保留自己的网络与账号。

## 面向玩家的目标流程

1. 按说明下载指定版本的 FX 虚拟机／启动器。
2. 自行安装游戏并登录 Steam。
3. 下载本项目并运行入口，选择或自动识别 FX 安装位置。
4. 首次运行检查并准备匹配的 FEX、Proton/Wine 组件；已经满足条件时不重复安装。
5. 网络使用玩家自己的连接。需要显式代理时填写自己的地址和端口，不要求特定代理软件或节点。
6. 启动游戏，报告真实的进程与 EAC 检查结果；运行失败时给出对应阶段的错误。

## 审计发现

| 当前条件 | 对别人电脑的影响 | 通用版需要的处理 |
| --- | --- | --- |
| FX 路径固定为项目内的专用副本 | 普通安装位置无法直接使用 | 识别或选择安装位置，校验兼容能力 |
| 专用 FX 可执行文件 SHA-256 校验 | 版本号相同也不一定通过 | 核实公开发行版与本地副本差异，建立经过验证的版本清单 |
| 补丁 FEX、Proton/Wine 只做匹配检查 | 下载普通 FX 后仍缺兼容组件 | 补齐精确下载／构建来源、安装与回退流程 |
| 必须使用定制 gvproxy-eim | 只下载 FX 和脚本可能缺转发组件 | 将其作为可复现的虚拟化依赖处理，不能当作个人代理配置忽略 |
| 强制本机端口 7890、Guest 网关代理 | 直连或其他代理端口也会被拒绝 | 将显式代理设为用户配置；验证不注入代理时的启动路径 |
| 检测到 TUN 仍保留游戏 HTTPS 代理 | TUN 用户仍被要求准备 7890 | 不仅凭 TUN 存在推断网络健康；由用户选择并验证路径 |
| 配置流程可启动 FlClash、调整 Guest IPv4、配置 Steam 代理 | 对他人的网络产生预期外影响 | 显式、可选的网络准备动作；不复制作者节点或有线方案 |
| 固定 CPU／内存预算 | 小内存或不同芯片机器可能不适用 | 根据资源提供可调整配置与兼容范围 |

当前后端、认证模块保持原样，所以这些问题仍然存在；本文件是审计与架构说明，不表示功能已经实现。

## 推荐边界

- 兼容层准备：固定经验证的 FX/FEX/Proton 组合，识别安装位置，校验组件并提供备份／恢复。
- 网络配置：不随仓库携带节点、订阅或个人配置。使用现有系统／虚拟机网络和用户主动填写的代理；不能从作者成功方案推断其他环境也必须如此设置。
- 游戏启动：保留已确认的游戏兼容参数，独立呈现游戏进程和 EAC 状态。
- 诊断：默认只读；路径探测结果只证明对应探测，不自动证明游戏匹配成功。

不要求使用者复刻作者 Wi-Fi、有线、FlClash、TUN 或节点组合。游戏自身必需的外网服务仍必须可达；网络独立配置不意味着可以承诺所有网络都能启动或联机。

## 验收条件

- 从公开下载的指定 FX 开始，在干净用户环境完成依赖准备，不能借用作者 Guest 中已有的补丁或文件。
- 安装位置不同、没有 FlClash、没有 7890 监听时，不因作者网络假设而提前拒绝。
- 显式代理使用用户自己的地址／端口，不把代理认证写进配置、日志或启动参数。
- 启动失败能区分组件、Steam 登录、网络、游戏进程与 EAC 阶段。
- 至少一次在独立环境的真实启动验证；离线模拟通过不能替代这一项。
