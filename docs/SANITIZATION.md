- `127.0.0.1` / `localhost`：回环地址。
- `192.168.127.254` / `7890`：该方案的 Guest 到 Host 网关／代理端口；不是作者公网地址。
- `1.1.1.1`：公共路由检查目标。其余内网、文档地址及伪订阅 URL 出现在合成测试中。
- `steamos`、`Path.home()`、Steam App ID 553850、SteamID 转换常量、端口和组件 SHA-256：通用技术参数；没有包含真实 SteamID。
- 测试中的 `SECRET`、`synthetic-secret`、带认证信息的假 URL：用于断言脱敏行为，均为合成字符串。
