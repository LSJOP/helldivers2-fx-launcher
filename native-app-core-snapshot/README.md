# Native Phase 1 read-only compatibility snapshot

Exact copies of the seven modules used by the existing Native bridge and its VERSION. This supplement preserves local Native development dependencies without changing the archived launcher. The original launcher remains at commit 0205acaec3b32024df180a6dfb8ecc587e2f1914. Native builds pin this archive commit through a submodule; they never execute archived menu or startup entrypoints. No runtime binaries, settings or artwork are included.
